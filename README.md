# Rusted Шпижион Студия 0.1.0

Программа созданная для быстрого нахождения фотографий для вдохновления и последующего копирования их в фоторедактор для в заимствование...

Внимание!
Программа целиком и полностью сделана при использовании и полном доверии искусственного интеллекта. Все, что вы читаете, включая сейчас создано с использованием искусственного интеллекта. Если вы против искусственного интеллекта немедленно закройте проект, пока не стало слишком поздно.
Хотя и вправду искусственный интеллект самостоятельно кот, я пытаюсь заниматься так называемым, чекингом, что он тут написал... Хотя и чаще всего это все чистый мрак, который работает на святой силе...
Ниже агент обычно любит приложить, увлекательную документацию о том, что ж этот проект прямо сейчас умеет, или не умеет, если он забудет, или не захочет, то тут будет примерно ничего.

## Памятка по GitHub Release notes

Release notes предназначены прежде всего для обычного пользователя. Пишите коротко и понятно: что добавилось, что исправилось и что стало удобнее. Не помещайте в пользовательскую часть логи сборки, номера коммитов, трассировки исключений, названия внутренних классов и другие технические записи.

Рекомендуемый формат:

```markdown
## Для пользователя
- Добавлена новая возможность.
- Исправлена заметная ошибка.
- Улучшено удобство работы.

## Технические детали
- Здесь можно хранить информацию для разработчиков, если она действительно нужна.
```

В интерфейсе «Что нового» показывается только пользовательская часть до секции `## Технические детали`.

## GitHub Releases для обновлений

Репозиторий релизов: `https://github.com/YaraYT/RustedSpiwiStudio`

Для автоматического обновления релиз должен содержать один опубликованный `.exe`-asset. GitHub REST API предоставляет для release asset поле `digest` вида `sha256:<64 hex>`, и студия сравнивает его с SHA-256 скачанного файла перед заменой текущего EXE.

Обновление заменяет только `RustedShpizhionStudio.exe`. Файлы `config.json`, `config.json.bak`, `index.db`, SQLite `-wal`/`-shm`, `rwmod-cache`, `app.log` и прочие portable-данные намеренно не затрагиваются.
