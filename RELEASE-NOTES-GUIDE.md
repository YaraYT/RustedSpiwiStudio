# Памятка по Release Notes

## Для обычного пользователя
Пишите только человеческие изменения:
- что добавилось;
- что исправилось;
- что стало удобнее;
- важные изменения поведения программы.

Не перегружайте этот раздел логами, stack trace, номерами коммитов, именами внутренних методов и прочей инженерной археологией.

## Для разработчика
Если техническая информация необходима, помещайте её после отдельного заголовка:

```markdown
## Технические детали
- ...
```

Приложение при показе истории релизов оставляет пользователю только текст до этой секции.
